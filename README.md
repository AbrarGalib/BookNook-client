# BookNook - Online Book Borrowing Platform

Welcome to **BookNook**, a full-stack modern web application designed for book lovers to explore, manage, and borrow their favorite titles seamlessly. 

🌐 **Live Site URL**: [https://booknook-livid-three.vercel.app](https://booknook-livid-three.vercel.app)

---

## ✨ Features

* **User Authentication & Authorization**: Secure user registration and login workflows powered by Better Auth, ensuring protected user sessions and data privacy.
* **Extensive Book Inventory**: Browse through a dynamic collection of books with real-time stock availability and detailed view pages.
* **Seamless Book Borrowing System**: Authenticated users can easily borrow available books, automatically updating inventory quantities in real time.
* **Personalized Borrow Records**: Dedicated dashboard views where users can track their active borrowed books and manage return dates.
* **Responsive Modern UI**: Built with Next.js 15 and Tailwind CSS, featuring smooth component transitions, interactive sliders via Swiper.js, and a fully mobile-optimized layout.

---

## 🛠️ Tech Stack

* **Frontend**: Next.js, React, Tailwind CSS, Better Auth, Swiper.js
* **Backend**: Node.js, Express.js, JSON Web Tokens (JWT)
* **Database**: MongoDB & MongoDB Node.js Driver
* **Hosting & Deployment**: Vercel
